# A4-Member-Management-System
A system that acts as a "source of truth" of the details of each member of the Mount Zion Church of The Firstborn (MZCF) Area 4. Furthermore, this system expands to 3 modules: Attendance, Tithes &amp; Offering, and Events. This system is crucial in tracking and managing church members as well as using that to streamline other administerial activities.
